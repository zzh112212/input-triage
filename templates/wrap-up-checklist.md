# 收尾清账清单

> 任务收工前逐项打勾。全部完成才算干净收场。

## 1. 搁置区清账

- [ ] ASK 逐项补答（简短克制，一两句话）
- [ ] NOISE 逐项处置（顺手答 / 建议立项 / 礼貌略过）
- [ ] 搁置区无 pending 项（每项 answered / converted / dropped 三选一）

## 2. 干净台账

- [ ] 任务台账已生成/更新（task-log.md）
- [ ] 正文零噪声内容（防污染话术自查）
- [ ] 每条 ADD / CORRECT 有裁决记录（决定 — 理由 — 代价）
- [ ] 步骤时间线与真实任务列表一致

## 3. 终局报告

- [ ] 四段齐全：完成了什么 / 我做的裁决 / 搁置处置 / 需要你决定的
- [ ] 裁决与搁置项穷举，无静默消失

## 4. 交接对接（若使用 context-continuity）

- [ ] handoff.md 引用台账吸收记录
